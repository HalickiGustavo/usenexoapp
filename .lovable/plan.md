# Formulário de contato na página da Nexo

## O que será criado
- Adicionar uma seção “Fale com a Nexo” antes das perguntas frequentes.
- Incluir campos obrigatórios para nome, e-mail e WhatsApp.
- Validar os dados antes do envio e mostrar mensagens claras de erro ou sucesso.
- Salvar cada contato no banco da Nexo para acompanhamento comercial.
- Adicionar um atalho “Contato” no menu superior.

## Detalhes técnicos
- Criar uma tabela protegida para os contatos, sem leitura pública.
- Enviar os dados por uma função segura no servidor com validação Zod e limites de tamanho.
- Manter o formulário adaptado para celular e alinhado ao visual atual da página.
- Validar o envio real e revisar a página em computador e celular.
